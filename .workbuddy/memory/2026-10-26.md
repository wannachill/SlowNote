## 统计页折线图错位 · 诊断与修复提示词

- 现象：`pages/statistics` 成长趋势 canvas 不画在白色卡片内，浮在指标卡上方或跑到页面底部盖住 tabBar，两次截图位置不同。
- 对照证据（已核实）：全项目调 `plot()` 三处——`growth`（canvas 在 `.page`，scroll-view 只在底部登记面板）、`monthly-report`（无 scroll-view）都正常；**只有 `statistics` 把 `canvas type="2d"` 放进带 `enhanced` 的 `scroll-view`**，且是唯一「页面级 `enablePullDownRefresh` + scroll-view `refresher-enabled`」双下拉并存的页面。
- 次因：`plot()` 在 `setData` 回调里同步测量（同一帧撤骨架屏 + `wx:if` 首挂 + scroll-view `flex:1;height:0` 重算），尺寸只取一次、未取整、无并发取消（`onPaletteChange` 与 `load()` 可能连画两次）；`.statistics-chart` 缺 `position: relative; overflow: hidden`。
- 数据侧不是 bug：体重/身高各自 min/max 独立缩放，交叉是设计如此（图例已写）；仅 2 个数据点时两点连线本就是长直线，视觉上更像错乱。
- 产出 `docs/statistics-chart-fix-prompt-20261026.md`：Step1 取证（打印 size/rect/dpr，判 343×160 是否为实测值）→ Step2 去 `enhanced` → Step3 只留一套下拉 → Step4 chart.js 加固（尺寸守卫重试、整数化、setTransform、token 取消、尺寸变化才重绘、`wx.nextTick` 后画）→ Step5 Fallback 改页面级滚动（对齐 growth，header 用 sticky）→ P1 少于 3 点不做满幅斜线。
