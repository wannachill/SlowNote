## 图表空白修复：viewClip → viewOffset 平移（2026-11-09 15:19，已直接改代码）

- 用户截图真机确认：横滑后图表左侧一大片空白，折线/横轴刻度仍跑到卡片右边缘外，右边缘外还有孤立数字。**上一条 viewClip 方案作废**。
- **根因**：canvas 2d 位图固定在卡片左端，**根本不随 scroll-view 的 scrollLeft 移动**（CSS 也裁不到）。把 clip 窗口设成 `[scrollLeft, scrollLeft+视口宽]` 后：容器内 `[0, scrollLeft)` 全是透明 → 空白；`[视口宽, scrollLeft+视口宽]` 被画到卡片外 → 溢出。
- **正确解法（不用改 wxml / canvas 宽度，改动很小）**：裁剪窗口**固定在画布 `[0, viewWidth]`**，用 `ctx.translate(-viewOffset, 0)` 把逻辑几何平移进来；`clipViewport()` 改为只更新 `geometry.viewOffset / viewWidth`（offset 上限 `geometry.width - viewWidth`），`paint()` 首帧用 `chartScrollLeft` 初始化；位图右侧全透明。`drawFrame()` 无条件 save/restore，clip+translate 在 save 之后、所有绘制之前。
- **点击坐标**：canvas 元素随 WXML 滚动而位图不滚，`onChartTap` 改用**不滚动的 `.chart-body`** 的 boundingClientRect 作基准，`physicalX + viewOffset` 再传给 `dateAtX()`；否则点选日期偏一个滚动距离。
- 测试：`chart-selection.test.cjs` 的 viewClip 用例改为断言 rect 恒 `[0,0,viewWidth,height]` + translate `[-offset,0]` + offset 受上限约束；`statistics-detail.test.cjs` 同步，并新增「滚动后点击」用例（clientX 150 / rect.left 50 / offset 200 → '2026-10-05'）。全量 **195/195 通过**。
