# 一迈一记（SlowNote） 后端与外部服务边界

> 后端方案：微信云开发（云函数 + 云数据库 + 云存储）
> 更新日期：2026-11-11

## 1. 始终适用的服务边界

- 列出所有外部 API、SaaS、云能力和端侧存储的所有者、用途、数据范围与退出方案。
- 外部调用必须定义认证、超时、重试、限流、幂等、错误映射和降级。
- 客户端不保存长期密钥；日志不记录令牌、完整个人信息或敏感载荷。
- 上下游契约变化必须可检测、可回滚并通知责任方。

| 依赖 | 责任方 | 数据范围 | SLA/限额 | 降级与退出 |
|---|---|---|---|---|
| 微信云数据库 | 本项目（cloud1） | 记录、任务、通知、运行态、回执、限流；按 openid / family_id scope | 单次聚合单页 100 条、单集合上限 10000 条 | 云函数是唯一写入口（`ai_sessions` 端侧写除外）；超限返回 413，不做伪完整结果 |
| 微信云存储 | 本项目 | 宝宝头像、日记图片、AI 临时音频 | 图片压缩后 ≤2MiB、单次至多 3 张 | 上传失败不阻断记录落库，提示后保留草稿 |
| LLM（OpenAI 兼容 Chat Completions） | 服务商，凭 `LLM_API_URL/KEY/MODEL/VISION_MODEL` | 脱敏对话、用户主动附带的记录明细白名单、已同意定时报告的所选类别明细、主动附带图片 | 明细按共享长度预算裁剪；关闭思考 18s、开启 45s 应用层超时；响应 ≤128KiB；不自动重试计费调用 | 未配置或失败只返回友好说明，不伪造结果；定时报告回退站内 |
| ASR（OpenAI 兼容 `/audio/transcriptions`） | 服务商，凭 `ASR_URL/KEY/MODEL` | 单段录音（mp3、16kHz 单声道） | 30s 超时；音频 1KiB–15MiB | 提示「语音转写服务未配置」，不阻断文字输入 |
| 订阅消息 `subscribeMessage.send` | 微信平台（模板与配额由平台控制） | 仅标题 + 北京时间，不含宝宝数值 | 一次性订阅，每次授权仅 1 条，可能耗尽 | 发送失败不影响站内报告；代码只要求模板含 1 个 `thingN` + 1 个 `timeN` |

## 2. 后端架构

- 接口层处理协议和输入；业务层表达规则；数据访问层封装存储；基础设施层适配外部系统。
- 身份校验与数据范围校验分离。服务端从可信上下文取得 `openid`；对象权限按真实关系验证 `entity_id`（若适用）。
- 写操作定义事务/补偿、幂等键和并发冲突策略。
- 错误使用稳定编码，不向客户端泄漏堆栈、SQL 或内部拓扑。

## 3. API 契约

| 项目 | 规则 |
|---|---|
| 输入 | 类型、范围、枚举、大小和文件内容均校验 |
| 输出 | 稳定结构；分页包含游标/总量约定 |
| 错误 | 可机器处理的错误码 + 可读消息 + 追踪标识 |
| 版本 | 破坏性变更通过版本或兼容窗口发布 |
| 幂等 | 写操作统一带 `clientRequestId`：记录类走确定性 `_id` + 原子 add，主键冲突即视为重复；可变对象在 `runTransaction` 内先查 `mutation_receipts`，未命中才更新并写回执，重放不会把新状态回滚为旧状态；调度侧用 `next_run_at` + `lease_until/lease_token` 原子认领，运行与通知 ID 由计划时刻确定 |

## 4. 可观测性与运行

- 结构化日志携带追踪标识，不携带敏感数据。
- 核心路径定义延迟、错误率、吞吐和业务健康指标。
- 健康检查区分存活与就绪；告警包含负责人和处置手册。
- 发布具备灰度、回滚、迁移检查与容量依据。

## 5. 云开发/云函数

- 函数最小权限、环境隔离、依赖锁定；限制并发、执行时长与返回大小。
- 校验云函数调用身份和数据库安全规则，不信任客户端传入用户标识。

## 6. 登录身份与功能可用性

- 所有已登录用户可使用全部产品功能，不存在模块级授权、功能锁定或管理员授权流程。
- 登录身份来自云函数可信上下文；`openid` 用于个人数据隔离。家庭共享、宝宝归属、记录所有权、同意状态、输入校验、频控和幂等仍按各业务契约验证。
- 前端登录门禁只负责引导登录，不代替云函数对身份和数据范围的校验。
- AI 模型地址、密钥、文本模型和视觉模型仅通过云函数环境变量 `LLM_API_URL`、`LLM_API_KEY`、`LLM_MODEL`、`LLM_VISION_MODEL` 配置；不得存入小程序包、数据库或文档。未配置时明确返回未配置状态。
- 问答只有用户确认发送并主动附带记录时才传明细；定时报告必须有任务级 consent 且只传所选类别。明细字段由共享 renderer 白名单控制，日记正文、里程碑事项名、辅食/自定义备注属于可能外发内容，发送前用 `redact()` 处理；任何 ID、原始时间戳及云文件 ID 均不得进入明细文本。

## 7. 验收清单

- [ ] 无后端时仅保留外部服务、安全与数据责任边界。
- [ ] 身份、数据范围、事务、幂等、错误和可观测性有实现与测试证据。
- [ ] 部署与迁移具备回滚路径。
