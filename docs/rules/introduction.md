# 一迈一记 SlowNote 项目说明
> 版本 1.8｜2026-11-11

一迈一记面向父母与照护者，记录喂养、成长、日记及宝宝生活。采用原生微信小程序与微信云开发；用户登录后可使用全部功能，登录身份用于数据隔离。

当前产品以三个固定底部入口组织（自定义 tabBar，SVG mask 线性图标）：
- 首页：宝宝昵称与月龄、周历/可展开月历、选中日期的记录卡、记录 FAB 与六类面板；不提供独立问小迈按钮。
- 小迈：今日/本周/本月/全部范围、通用问答入口和六类概况卡。只展示选定范围内有记录的类别卡片；没有记录的类别不显示。整个范围均无记录时隐藏「宝宝概况」卡片区，显示去首页登记的引导。有记录的卡进入统计详情页查看该类型指标、趋势图与选中日期的该类型明细；明细仅随点选日期变化，点选吸附到最近的有登记值日期，空白日期不切换、不请求后台；数值标签集合与选中态无关，每个有值点始终显示数值。成长/喂养为多项指标卡，统一三列：标签｜数值+单位｜环比变化，变化不重复单位；其余为单指标卡。
- 我的：登录/本机退出 + 宝宝信息卡，入口自上而下为主题设置 / 小迈设置 / 定时报告 / 历史报告，不在我的页内直接展开表单。原「信息推送」中转页已删除。

宝宝信息子页支持多宝宝档案（添加/切换/编辑/删除/头像上传，头像按性别默认或用户照片；生日用原生 `<picker mode="date">`（上限为今天））；主题子页提供 6 种渐变主题色（治愈蓝 / 樱粉 / 暖橙 / 薄荷绿 / 紫色 / 深色），以圆点选择器切换，无浅色/深色模式；定时报告子页配置按天/周/月生成并推送的成长报告；小迈配置页维护深度思考入口显示、回答/图片/报告提示词、锁定安全规则展示及常见问题（内置 + 自定义，支持新增/删除与固定展示）。宝宝信息与定时报告页统一使用「左滑卡片 + 底部表单」交互：卡片左滑展开编辑与删除、正面原生 switch 单独控制该任务的微信通知（报告任务）或点击切换当前宝宝，删除先弹统一确认弹层，成功后才移除卡片。智能提醒（pages/reminder、reminderRecord 云函数、reminder_items 写入、定时器）已于 2026-11-11 整体下线，与手机闹铃/日程重复且一次性订阅无法保证送达。

小迈提供通用问答与记录数据问答：主页面问答入口不绑定时间范围、不预填问题，进入对话后可自由提问；提问文本识别今天/昨天/周/月/近期范围并附加对应数字快照。常见问题支持按问题选择 7 类数据类型（多选、可全选），推荐问题只附带所选类别的记录摘要，避免每次把全量记录发给模型；便便/排尿与辅食摘要此前被 `buildText` 遗漏，现已补齐。当前个人主体不可用 WechatSI，语音由 RecorderManager 录音并在松开后通过 asrProxy 一次性转写；主体变更为非个人后可加回声明恢复实时预览。云函数自动注入当前宝宝性别与月龄上下文（不含昵称/生日原文）。模型通过云函数环境变量配置 HTTPS OpenAI 兼容接口；未配置时给出说明。定时任务支持每天/每周/每月；月度任务每月 1 日生成上月整月报告，先生成站内通知，再尝试订阅推送。无模板不真实推送；AI 不作诊断，异常情况引导就医。定时报告页（pages/ai-tasks）为任务配置入口：顶部蓝色「页面用途说明」提示卡（与「常见问题」同款），说明报告先存站内、可按卡片单独开启微信推送；**已移除全局「开启通知」按钮**。「＋ 添加」按钮弹出表单（数据类型 7 类多选 + 全选、数据范围 跟随频率/今天/近 3 天/近 7 天/近 30 天、频率、星期、时间、报告标题 ≤20 字；范围与频率解耦，月度任务固定上月整月并隐藏范围选择），数据类型选择与「新增常见问题」一致（标题行 + pill 标签）；列表卡片左滑编辑/删除 + 卡片正面原生 switch 单独控制该任务的微信通知（`notify`），卡片只展示标题、频率与时间；列表行统一 `--row-height` 最小高度、`--space-xs` 行距与 `--font-body` 标题，编辑走 aiTasks 的 action:'update'（复用新增校验、重算 next_run_at、清空租约）。报告正文落在 ai_notifications，由「我的 → 历史报告」（pages/ai-notifications）集中查看：顶部起止日期筛选（默认本月）；卡片两行布局——标题（取 `report_title`）与右侧发送时间、次行微信渠道短标签（`微信已送达`/`站内信`/`微信未送达`）与右侧「未读」标签，**不展示正文预览**；点击弹出详情面板查看完整正文并自动标记已读，左滑删除需二次确认（按钮宽度与常见问题等宽；云端 `aiNotifications` 的 `remove`，按 openid 校验归属、clientRequestId 幂等；`list` 支持日期筛选与 `offset` 分页，每页 20 条）。订阅消息字段为 thing1 报告类型、time2 生成时间、thing3 报告结果（任务「报告标题」，未配置则不展示），点击跳回历史报告；aiTasks 的 AI_REPORT_TEMPLATE_ID 为空时仅提示「微信通知尚未配置，报告仍会保存在站内通知」，不影响历史报告查看。

六类登记（顺序：喂养/辅食/便便/成长/日记/自定义）：喂养分亲喂/瓶喂/配方奶（mixed 仅历史兼容），辅食记录名称与备注，便便分大便/小便（记录次数，大便性状选填），成长记录身高/体重/头围，另有日记与自定义记录。自定义记录单位自由输入，前端最多 6 字。登录后可使用全部功能，数据仍按本人或当前家庭、宝宝范围隔离。旧药品/护理日常记录入口已移除；发育里程碑（pages/milestone）及其达成撒花保留。

全部页面使用自定义导航栏，标题字号全局统一 44rpx：Tab 页无顶部标题（页内大标题），子页面 .sub-nav 大标题 + 返回按钮，动态状态栏高度避让、与胶囊按钮同水平线；字体令牌统一（caption 28rpx 下限），中文字体栈覆盖各系统。不宣称医学百分位曲线、导出、桌面组件、系统日历同步或离线写入队列已经实现。
